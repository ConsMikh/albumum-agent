# Альбом и его листы в Albumum

Общие правила, подтверждение, коды выхода и повтор без дублей — в скилле `albumum`. Верстка
содержимого листа — в скилле `albumum-layout`.

## Альбом

```sh
albumum albums list                     # кратко: номер, название, дата, число листов, публикация
albumum albums list --full              # полностью: формат, описание, обложка, даты публикации
albumum catalog formats                 # форматы: стороны страницы и вид листа
albumum album create --title "Эльбрус" --date 2026-07-03 --format 3:2 --sheet spread
albumum album create --title "Дача" --date 2026-08-15 --format square --sheet single
albumum album get 7 -o album.json       # альбом целиком: свойства, стиль, листы с документами и ревизиями
```

- У `album create` все четыре параметра обязательны: `--title`, `--date`, `--format`, `--sheet`.
- `--date` (ГГГГ-ММ-ДД) — дата события; без нее система альбом не создает. Автор дату не назвал —
  спроси; не ответил или просит «как-нибудь» — поставь сегодняшнюю и скажи ему об этом (поменять —
  `album set --date`). Дату из снимков не выдумывай.
- `--format` — имя формата из `albumum catalog formats` (поле `name`: `square`, `3:2`, `a-portrait` …)
  или стороны страницы `ШxВ` (`1500x1000`). Неизвестное имя — код 1 со списком имен.
- `--sheet spread` — альбом разворотами (лист — две страницы со сгибом посередине), `single` — по одной
  странице. Титульная страница — всегда одиночный лист. Формат бери из `albumum catalog formats`, не
  выдумывай; спорно — спроси автора.
- **`single` или `spread`.** Формат (`square`, `3:2` …) задает одну страницу и не решает, листать
  альбом страницами или разворотами: «квадратный альбом» — это квадратная *страница*, а разворот будет
  вдвое шире. `single` — каждая страница сама по себе, без сгиба. `spread` — две страницы рядом как в
  раскрытой книге; по середине сгиб: лицо или текст на сгибе пострадают, широкий кадр можно раскинуть
  на обе страницы. Автор не сказал явно («разворотами», «как книга», «по одной странице») — спроси до
  `album create`: смена потом затронет листы.
- Оборвалась связь на `album create` — повтори с `--request-id` из ответа (скилл `albumum`, «Повтор без
  дублей»), иначе получишь второй альбом.
- `albums list` кратко: `published` — опубликован ли, `has_password` — есть ли пароль, `behind` — есть
  правки после публикации. Адреса для зрителей система агенту не отдает (скилл `albumum-publish`).
- Дальше работай с файлом `album.json`: в нем номера листов (`pages[].id`), их вид (`kind`), ревизии и
  документы. Перечитывай его после изменений.

## Свойства, формат и стиль

```sh
albumum album set 7 --title "Эльбрус, июль" --date 2026-07-03 --description "Неделя в горах"
albumum album format-check 7 --format 1000x1000 --sheet single   # какие листы затронет смена формата
albumum album set 7 --format 1000x1000 --sheet single
albumum catalog fonts                                             # шрифты с начертаниями (faces)
albumum album set 7 --style style.json
```

- `album set` отвечает кратко: номер альбома, `changed` — что изменилось, свойства и число листов
  (`page_count`); весь альбом — с `--full` или `album get`.
- **Смена формата**, затрагивающая листы, — код 2 с `preview`: перечень листов и что с ними будет
  (разворот режется по сгибу, элемент через сгиб уходит на одну половину). Сначала `album format-check`,
  покажи перечень человеку, «Применить? (да / нет)», после «да» — та же команда с `--confirm`.
- **Стиль** — объект `style` из `album.json`: `font` (любое имя из `catalog fonts`, в том числе убранное из набора — оно остается рабочим), `text_color`, `palette`
  (ровно 4 цвета `#rrggbb`), `page_background` (фон альбома), `viewer_background` (фон вокруг листа у
  зрителя), `page_photo` (фото фона альбома: `{"media": {"file": ID}, "crop": …, "effects": …}` или
  `null`), `title_photo` (`true` — фото фона и на титульной, `false` — нет). Возьми `style` из файла альбома, поменяй нужное,
  запиши в `style.json` целиком и передай `--style`. Неверное значение — 422 с `field`.

## Листы

```sh
albumum catalog templates 7                        # заготовки листа: имя, название, число мест
albumum catalog templates 7 --places 2             # только на 2 места под фото
albumum catalog templates 7 --kind title           # для титульной (for_title: true — сделаны для нее)
albumum catalog templates 7 --full                 # с документом заготовки (места, их id и подписи)
albumum pages add 7 --template ИМЯ --media 501,502,-,503   # лист из заготовки; «-» — место пустое
albumum pages add 7 --document page.json --position 3      # лист сразу с версткой (albumum-layout)
albumum pages add 7 --duplicate-of 41              # копия листа — встает сразу за оригиналом
albumum pages add 7                                # пустой лист в конец
albumum pages order 7 40 42 41 43                  # новый порядок: все листы альбома
albumum pages order 7 39 40 42 41 43               # то же с титульной (39) первой — тоже можно
albumum page template 7 41 ИМЯ --from page-41.json --media 501,-,502   # заменить верстку листа заготовкой
```

- `pages add` отвечает кратко: номер альбома, `added` — сколько листов добавлено, `pages` — их `id`,
  `kind`, `position`, `revision`; листы с документами и файлами — `--full`.
- Вертикальное фото, которое место обрезает по высоте, система ставит кадром к верхней трети (там
  обычно лица), остальные — по центру. Поправить кадр одного места — `albumum page fill` с `--crop`
  (скилл `albumum-layout`).
- `pages order`: перечисли все листы альбома по одному разу; титульная всегда первая — ее можно не
  указывать или поставить первой. Не совпало — код 1 с `missing` (каких листов не хватает) и `extra`
  (лишние: повторы, титульная не первой); поправь список и повтори.
- Файлы `--media` встают по местам заготовки по порядку; не хватило мест — добавится столько листов
  той же заготовки, сколько нужно (100 фото по заготовке на 4 места — 25 листов одной командой).
  Файл должен быть готов (`status: ready`) и нужного вида.
- Титульный лист у альбома один и создается вместе с альбомом: его верстку меняют `page template` с заготовкой
  `--kind title` или запись листа (`albumum-layout`).
- `pages add` — создающая: при обрыве связи повтори с `--request-id`.
- `page template` пишет лист по ревизии из файла `albumum page get` (скилл `albumum-layout`); конфликт
  ревизии — порядок оттуда же.

## Фон альбома на листах

```sh
albumum pages background 7 --from album.json            # все листы со своим фоном → фон альбома
albumum pages background 7 41 42 --from album.json      # только эти листы
```

Ревизии берутся из `album.json` — перечитай его перед командой. Больше 5 листов — подтверждение.

## Удаление

```sh
albumum page delete 7 41            # один лист в корзину
albumum pages trash 7 41 42 43      # несколько листов одним запросом: все или ничего
albumum album delete 7              # альбом в корзину — всегда с подтверждением
```

- Больше 5 листов, или шестое удаление подряд за 10 минут, — код 2 с `preview` (перечень листов).
  Удаляешь много — одной командой `pages trash` и один вопрос человеку, не по одному.
- `album delete`: предпросмотр называет число листов; у опубликованного альбома ссылка перестанет
  открываться. Покажи и жди явного «да».
- Вернуть — `albumum trash restore page:41` или `album:7` (скилл `albumum-library`).
