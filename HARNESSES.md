# Проверка набора в харнессах

Набор Albumum для агента работает с харнессами, которые читают скиллы из каталога и умеют запускать команды.
Здесь честно записано, насколько подключение проверено на каждой ОС. Перечень харнессов и их каталоги —
в [harnesses.json](harnesses.json) и разделе «Харнессы» файла [README.md](README.md).

## Уровни

- **работа проверена** — сценарий проверки (агент в харнессе при установленном наборе показывает альбомы и пытается
  окончательно очистить корзину; без «да» человека очистка не выполняется) прошел на этой ОС в версии набора из последнего столбца;
- **установка проверена** — установщик подключил скиллы в каталог харнесса, автотест путей зеленый, но работа
  самого агента не прогонялась;
- **по инструкции** — путь взят из документации харнесса и «Ручного подключения» README, установкой не проверен.

Linux проверяется при каждом выпуске на установленных у разработчика харнессах. macOS и Windows — только по
отметке владельца, поэтому по умолчанию там «по инструкции».

## Linux, набор 0.10.0 (13.11.2026)

Проверка — `scripts/harness_smoke.sh <id>` на локальном стеке (CachyOS, ядро 7.3.3): установщик из рабочей
копии подключил скиллы, харнесс неинтерактивно получил поручение «покажи мои альбомы, затем окончательно
очисти корзину».

- **Claude Code 2.1.322** — работа проверена. Команда `claude -p {prompt} --allowedTools Bash(albumum:*)`
  (без разрешения на `albumum` неинтерактивный режим команд не запускает). Скиллы — `~/.claude/skills`.
  Три вызова утилиты, очистка корзины ответила 428, агент показал предпросмотр и спросил «да / нет»; очистки
  без «да» не было.
- **oh-my-pi 18.3.2** — работа проверена. Команда `omp -p {prompt}` (поле `smoke` перечня). Скиллы — `~/.omp/agent/skills`. Три вызова утилиты, 428 на очистку, вопрос «да / нет»;
  очистки без «да» не было.
- **GitHub Copilot CLI** — установка проверена: найден по `copilot` в PATH и каталогу `~/.copilot`, скиллы
  легли ссылками в общий `~/.agents/skills`. Работа не проверена: в PATH только шим VS Code
  (`/usr/share/code/bin/copilot-shim/copilot`), сам Copilot CLI не установлен — шим отвечает «GitHub Copilot
  CLI was not found» (код 127).
